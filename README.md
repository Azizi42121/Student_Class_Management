# STUDENT & CLASS MANAGEMENT

Sistem manajemen kelas dan siswa yang menjadi tempat penyimpanan data pendidikan yang terstur dan mudah digunakan.

## Fitur Utama (MVP)

- [] **Pengelolaan master kelas** : Tambah kelas, daftar kelas, detail kelas
- [] **Pengelolaan master siswa** : Registrasi siswa, pencarian & filter siswa, update & mutasi sederhana, hapus siswa
- [] **Validasi aturan bisnis dasar** : Cegah data yatim (orphan data), NIM/NIS unik

## Tech Stack

- **Backend / language** : Python (FastAPI)
- **Database** : SQLite
- **Frontend** : HTML, JavaScript, Tailwind CSS
- **Tools & Testing** : Git dan Swagger UI
